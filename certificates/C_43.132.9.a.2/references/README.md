# References

- van Hoeij's list of low-degree places on X_1(N),
  <https://www.math.fsu.edu/~hoeij/files/X1N/LowDegreePlaces>, and his slides
  <https://web.math.pmf.unizg.hr/~fnajman/MC_talks/vanHoeij.pdf> were consulted; they are not
  redistributed here, and no script uses them.
- `x043_modelmaps.json` is the retained LMFDB `modcurve_modelmaps` record
  58354 for the \(j\)-map on the stored \(X_0(43)\) model.
- `x043_jmap_polynomials.m` is a mechanical Magma extraction of the
  numerator and denominator in that JSON record.

van Hoeij's data motivated the search for descended low-degree CM
places.  The LMFDB map data makes the CM-fiber computations reproducible
without another database request.
